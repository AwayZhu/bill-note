# 个人记账 App

只给自己用的安卓记账 App。**只安卓 · 数据全本地 · 不登录 · 不联网 · 零第三方依赖。**

## 怎么在手机上打开预览版

**方式一（推荐）：双击**
```
scripts/start-preview.bat
```
双击就行，**不需要输入任何东西**。一两秒后浏览器会自动打开一个引导页，上面有：

- 「打开记账 App」按钮（电脑上直接用）
- **手机地址**（形如 `http://192.168.x.x:8000`），在手机浏览器里输入即可

> 关键：**关键信息在浏览器那一页上，不在黑窗口里。**
> 就算命令行显示成乱码也不影响你使用。

**方式二：命令行**
```bash
python scripts/serve.py --lan            # 允许手机通过 WiFi 访问
python scripts/serve.py --lan --no-open  # 不自动弹浏览器
python scripts/serve.py 8123             # 换端口（8000 被占用时会自动往后顺延）
```

### 出问题先看这里

| 现象 | 原因和办法 |
|------|-----------|
| 命令行一堆乱码、报「xxx 不是内部或外部命令」 | bat 文件编码问题。**已修复**——现在的 bat 是纯英文，不会再出现。如果你手改过它，务必存成 ANSI/纯英文 |
| 双击没反应、一闪而过 | 多半是没装 Python。`where python` 检查；没有就去 python.org 装，**安装时必须勾 "Add python.exe to PATH"** |
| 手机打不开那个地址 | 确认手机和电脑连的是**同一个 WiFi**（用手机流量不行）；还不行多半是电脑防火墙拦了，临时关掉试试 |
| 浏览器白屏 | 你是不是直接双击了 `index.html`？那样走的是 file:// 协议，ES 模块会被浏览器拦掉。**必须从引导页进去** |
| 提示端口被占用 | 换端口：`python scripts/serve.py 8123` |

> 为什么不能直接双击 `index.html`：它用的是 ES 模块，浏览器在 `file://` 协议下会拦截模块加载（白屏）。
> 必须走 http，这也是上面的脚本存在的唯一原因。
> **首次使用时浏览器的 IndexedDB 会存在浏览器数据里，别清缓存；正式版打包成 APK 后数据会搬到 App 私有目录。**

## 交付前必跑：自测

```bash
node scripts/selftest.mjs   # 静态检查：模块引用 / 金额日期逻辑 / 交付物完整性
node scripts/smoke.mjs      # 真实 DOM 冒烟：把 App 跑起来点一遍（需 jsdom）
```

`selftest.mjs` 检查三件事：
1. **模块引用**——有没有引用不存在的模块、导入不存在的导出、引入第三方依赖
2. **金额与日期核心逻辑**——整数分转换、格式化、跨年月份推移、月份边界归属
3. **交付物完整性**——关键文件是否齐全、有没有偷偷引入外部资源

**它已经抓到过两个会导致白屏的致命 bug**（模块路径越级、`uid` 从错误的模块导入）。

`smoke.mjs` 是第二道关：用 jsdom 把整个 App 真跑起来，逐个页面渲染、模拟点击，
验证「点完之后确实按预期变化」。**翻月连点 5 次的回归测试就在这里**——
它能在几秒内重现那次「点一下翻到 2037 年、越点越卡」的故障。

依赖只需装一次（装在托管目录，不污染系统）：
```bash
cd C:/Users/LENOVO/.workbuddy/binaries/node/workspace
npm install jsdom fake-indexeddb
```

每次改完代码、打包之前都跑一遍。

## 目录结构

```
src/
  index.html            唯一入口
  css/app.css           全部样式
  js/
    util.js             金额/日期/格式化（纯函数，无依赖）
    logger.js           日志环形缓冲 + 崩溃捕获 + 复现步骤记录器
    repository.js       IndexedDB 封装（数据层，唯一碰数据库的地方）
    seed.js             默认账户与分类
    store.js            领域层：内存缓存、增删改、预算、统计
    charts.js           自绘 canvas 饼图与柱状图（不引第三方图表库）
    lock.js             应用锁：PIN 设置 / 校验 / 锁屏界面
    diagnostics.js      诊断面板：数据采集与报告生成
    app.js              入口、路由、弹层容器
    views/              五个页面：record / ledger / stats / accounts / settings
scripts/
  serve.py              本地静态服务
  start-preview.bat     双击启动
  selftest.mjs          自测脚本
docs/                   方案与决策记录
```

### 关于记账页的键盘让位

金额和键盘是一组，钉在屏幕底部。**手一滑开始翻内容，键盘自动滑出屏幕让地方；
手停下来约 0.4 秒（或手指一按），键盘自动滑回来。** 金额那条永远在，不会跟着滚走。

嫌回来太快或太慢：改 `src/js/views/record.js` 里的 `COLLAPSE_DELAY`（当前 400，单位毫秒），
数字调大就慢一点，调小就快一点。

### 关于安卓原生日期选择器

记账页「日期」那一行的输入框就是原生选择器：**点一下日期，安卓会弹出系统自带的滚轮日历**
（各品牌长得不一样，小米/华为/三星各不相同，这是系统控件，不是我画的）。

如果没弹出，先确认点的是日期输入框本身，不是旁边的「今天/昨天/前天」快捷键。
打包成 APK 后它同样是系统控件。
