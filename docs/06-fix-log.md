## 问题 2、3：翻月翻到 2037 年、越点越卡

**现象**：明细页和统计页点「下月」，2026-09 → 2027 → 2037，间隔越来越大；
而且越往后点，等待时间越久。

**根因（架构级）**：`app.js` 把常驻的 `#screen` 元素直接传给视图，
而每个视图都在 `render()` 里执行 `root.addEventListener('click', ...)`。

```
第 1 次渲染 → 挂 1 个监听器
点「下月」 → 1 个监听器响应 → 翻 1 个月 → 重渲染 → 挂第 2 个监听器
点「下月」 → 2 个监听器响应 → 翻 2 个月 → 重渲染 → 挂第 3 个监听器
点「下月」 → 3 个监听器响应 → 翻 3 个月 …
```

月份步长变成 1、2、3、4…，而且每次点击触发 N 次完整重渲染，
每次重渲染又新增一个监听器 —— **是指数级膨胀，不是线性变慢**，
所以「越往后等待时间越久」，最终会卡死。

**修法**：每次渲染给视图一个全新的容器元素，监听器随元素一起被回收。

```js
const holder = document.createElement('div');
holder.className = 'view';
await view.render(holder, apiRef);
screen.innerHTML = '';
screen.appendChild(holder);
```

一处改动同时修好 5 个页面。**不是给每个视图打补丁，而是改渲染契约本身。**

顺带加了「回本月」按钮：万一翻远了，一键回来。

## 问题 1：首页「出错了，页面没能正常打开」

**根因**：`src/js/views/record.js` 里 `_keyHandler = onKey;` 引用了 `onKey`，
但这个函数在之前的一次编辑中被整个删掉了 → `ReferenceError: onKey is not defined`。

抛错发生在 `root.innerHTML = html()` 之后，所以页面先渲染出来、然后被错误页替换，
而 `boot()` 因此提前 return，导致点 tab 还能用、唯独首页报错。

**修法**：补回 `onKey`（电脑键盘记账用，手机用不到但不能没有）。

**顺带加固**：错误页现在会显示完整错误信息 + 堆栈，并提供
「复制错误信息」「打开诊断面板」「重试」三个按钮。
以后再遇到，直接点复制发给我就行，不用再手打。

## 关于应用锁的两条诚实说明

1. **没有找回方式。** PIN 只存在本机，忘了只能清空数据重来。
   连续错 5 次后锁屏会出现「忘了密码？清空数据重新设置」，但那是最后手段。
   **开启前请先导出一次备份。**

2. **密码哈希的强度取决于运行环境。** 打包成 APK 后是安全上下文，用 SHA-256；
   但预览版走 `http://192.168.x.x`，浏览器不提供 `crypto.subtle`，
   会退化为 FNV-1a —— 只能防随手翻看，防不了专业提取。
   **这是预览版的临时妥协，不是最终方案。**

## 第二轮真机反馈（2026-09-10 晚）

### away 报的 2 条 + 诊断报告解读

**1. 记账时数字和键盘离太远，打字看不到数字**

根因是**视口不够高**：他的物理屏 800px，浏览器地址栏吃掉 93px，实际只有 **707px**。
而记账页从上到下约 940px —— 金额在 150px 处，键盘在 660px 以下，一屏装不下两者。
最大占地方的是分类网格：13 个支出分类排 4 行，吃掉近 300px。

**away 选择方案 B「金额跟随键盘」**：
- 金额 + 键盘提取到**底部固定区** `.record-dock`（`position:fixed`，挂在 body 上，位于 tabbar 之上）
- 分类网格、账户、日期保留在滚动区，金额不再跟着滚走
- 内容区末尾插入等高空位 `#dockSpacer`，由 JS 按固定区实际高度回填，避免遮住最后一行
- **点备注时自动收起自定义数字键盘**（`note-on` class），避免和系统输入法叠成两个键盘
- 切页时 `cleanup()` 移除固定区，防止残留在别的页面上
- 概览条按他要求**保持原样**（默认展开）

> 注意：打包成 APK 后是全屏，会多出那 93px，布局会明显宽松。

**2. 诊断报告**

| 报告内容 | 结论 |
|---------|------|
| `[异常] 非信用卡账户余额为负: 1` | **不是 bug，是数据**。没设期初余额（默认 0）就转出 50 元 → 余额 -50。去账户页填「期初余额」即可。信用卡为负不告警 |
| 权限三项 denied | 预览版正常。`persistent-storage: denied` 有真实含义：**浏览器存力紧张时可清掉 IndexedDB** |
| 日志里成片的 `route -> xxx` | 点几次就是几条，属正常。判定标准：**点一次出现两条以上**才是没刷新干净 |
| 视口 360x707 / 物理 360x800 | 差的 93px 是浏览器地址栏。打包 APK 后恢复全屏 |

针对 `persistent-storage` 风险，新增「我的 → 存储保护」：一键申请持久化存储
（`navigator.storage.persist()`），拿到后浏览器就不会自动清理。打包 APK 后天然免疫。

## 第三轮真机反馈（2026-09-10 18:10）

### away 的验证结果
1. 翻到分类网格最下面，金额仍在键盘上方 ✅
2. 点「备注」输入时，自定义数字键盘会自动收起 ✅
3. **新需求**：金额和键盘固定到一起已达成，但还要「随着页面滚动」

### 「随着页面滚动」的歧义澄清
这句话至少有三种可能，差别很大，直接用图把三种做法的**视口分配**算给他看：

| 做法 | 内容可视区 | 金额是否始终可见 |
|------|-----------|-----------------|
| 现状·永远钉住 | 315px（约 2 行分类） | 是 |
| 滚动时键盘让位 | 595px（约 4 行分类） | 是 |
| 整组跟随页面滚 | 649px | **否，要滚到底才看得到** |

他用 AskUserQuestion 选了 **「滚动时键盘自动让位」+「停手自动回来」**。

### 实现要点
- `keypadHtml()` 外面包一层 `.keypad-wrap`，收起靠 `max-height:300px → 0` + `opacity` 过渡
- `onScroll()`：滚动 → 加 `collapsed`；debounce **400ms** → 移除
- 额外挂 `pointerdown`（capture）：手指一按立刻回来，不用等 400ms
- 备注输入时 `note-on` 同样收起，滚动监听直接 return 不干预

### 关键决策：收起时刻意不动 spacer 高度
如果收起时把 `#dockSpacer` 缩掉，会形成
**文档变短 → 浏览器修正 scrollTop → 又触发 scroll → 再收起** 的抖动死循环。
因为收起只是"暂时离场"（停手就回来），spacer 保持展开态高度即可，文档长度恒定。

### 自证
`selftest.mjs` 40 项 + `smoke.mjs` **64 项**全过。新增 [1c] 段 6 项：
包裹层存在 / 初始展开 / 滚动即收起 / 滚动中保持 / 停手 400ms 回归 / 手指一按立刻回来。
**反向验证**：把 `collapseKeypad()` 改成空函数 → 2 项立刻失败，证明断言有效。

### 可调参数
嫌回来太快/太慢：改 `src/js/views/record.js` 里的 `COLLAPSE_DELAY`（当前 400，单位毫秒）。

## 第四轮：回退到「整组跟随页面滚动」（2026-09-10 19:10）

### away 的决定
上一轮「滚动时键盘让位」他不喜欢，明确要求：**回退到整组跟着页面滚动的版本**。
用 AskUserQuestion 澄清摆放位置后，他选 **「放在页面最末尾」**——即恢复改之前的布局，
唯一保留的改进是：**金额和键盘始终粘在一起**（不再像更早版本那样金额和键盘中间隔开分类网格）。

### 实现（回退 + 保留粘在一起的改进）
- `contentHtml()` 顺序：概览 → 类型 → 备注 → 分类 → 账户 → 日期 → **金额+键盘整组（recordDock）**
- `recordDock` 现在是**普通文档流元素**（CSS 去掉 `position:fixed`，改回 `margin/border/radius`），
  跟着页面一起滚，要滚到底才出现——这正是他想要的行为
- 金额与键盘仍是紧邻片段（`dock-amt` → `dock-sub` → `keypad-wrap`），中间不插其他区块
- 切页时整组随 `root`（screen 内容）一起被回收，`removeDock()` 只断引用，无需从 body 摘
- **保留** note-on 收起：点备注唤起系统输入法时，自定义数字键盘仍自动收起，避免双键盘重叠
  （`.keypad-wrap` 的 max-height 放宽到 480px，正常显示不会被裁切）

### 自证
`selftest.mjs` 40 项 + `smoke.mjs` **62 项**全通过。
[1b] 段改为「整组跟随滚动」断言：整组在滚动内容里 / 在内容末尾无多余 spacer / 金额与键盘紧邻。
[1c] 段改为 note-on 断言：点备注聚焦键盘收起、失焦恢复。
指向已删除行为（fixed 不在内容里、滚动收起、spacer）的旧断言全部移除，避免误报通过。
