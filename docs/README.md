## 一句话结论

> ⚠️ 已于 2026-09-10 拍板，范围见 [05-decisions-baseline.md](./05-decisions-baseline.md)。
> **A1 分账户 ✅ · A2 预算 ✅（提前进 MVP） · A10 首页＝记账键盘 ✅ · A11 统计四视图全选 ✅ · 默认分类必须支持自定义新增 ✅**

MVP 做 8 件事：**记一笔 / 账户 / 分类 / 明细 / 统计四视图 / 预算 / 备份 / 诊断面板**。
其余（固定收支、借还、标签、小票、余额曲线）全部排到二期，按你实际用到再开。

最大的风险不是功能不够，而是**不联网 = 没有云同步 = 手机丢了账就没了**。
所以"本地自动备份 + 一键导出"在 MVP 里是必选，不是可选。
