## A10 方案 A 的具体设计（重要）

打开就是记账键盘，意味着**输入速度是这个 App 的第一指标**。据此定了三条：

1. **零额外点击**：不弹窗、不跳转，App 起来后数字键盘就是焦点，抬手就能按。
2. 本月概览不抢位置，压缩成键盘页顶部一条：`本月已花 ¥1,234 · 预算剩余 ¥566`，点一下才展开。
3. 分类用**九宫格**（不用下拉框），常用分类自动排前面。

代价：打开 App 看不到全局。但你自己用，记一笔是最高频动作，这个取舍是对的。

不登录意味着别人拿到你手机就能看全部账目，这是目前唯一的安全敞口。

## MVP 范围（本次要交付的）

1. 记一笔（支出/收入/转账 + 自定义金额 + 分类九宫格 + 账户 + 日期 + 备注）
2. 账户管理（现金/储蓄卡/信用卡/支付宝/微信，余额实时算）
3. 分类管理（预置 + 自定义新增，增删改排序）
4. 明细流水（按天分组，筛选，编辑，软删除）
5. 统计四视图（饼图 / 月度趋势 / 同比环比 / 排行榜）
6. 预算（月度总预算 + 分类预算，超支标红）
7. 备份（导出 JSON / CSV，导入恢复，上次备份时间提醒）
8. 诊断面板（6 组信息 + 3 个操作，见 `04-diagnostics-panel.md`）
