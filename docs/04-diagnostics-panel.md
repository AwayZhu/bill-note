# 04 — 诊断面板规格

## 为什么要这个

你之前报 bug 是"点了就是失败"，我只能猜原因，导致同一个功能反复返工。
这个面板的目的：**让你不用看 logcat、不用懂技术，也能一次把信息报全。**

## 入口

设置页 → 关于 → **连点「版本号」5 次**进入（防误触）。
同时：设置页顶部常驻一个**健康指示灯**（绿/黄/红），异常时一眼能看到。

## 面板内容（6 组）

### 1. 运行环境
- App 版本 + 构建号 + 构建时间
- 运行壳：`浏览器预览` / `原生 App`
- Android 版本、设备型号、屏幕分辨率与 DPR
- 系统语言、时区
- 可用存储空间

### 2. 存储健康
- 存储引擎：`IndexedDB` / `SQLite`
- schema 版本 + 目标版本（不一致会标红）
- 数据库文件路径
- **可写性自检**：写入测试记录 → 读回 → 删除，三步结果分别显示 ✓/✗
- 记录数：交易 / 账户 / 分类 / 日志
- 数据库占用体积
- **距上次备份：X 天**（超过 7 天标黄，超过 30 天标红）

### 3. 权限状态
存储读写 · 通知 · 相机 · 生物识别 —— 每项显示 已授予 / 未授予 / 未申请

### 4. 数据完整性自检（自动跑，异常项标红）
- 孤儿交易：指向了已删除的账户或分类
- 金额为 0 或负数
- **账不平**：账户余额 ≠ 期初余额 + 流水汇总
- 疑似重复：同金额、同账户、10 秒内的多笔
- 转账记录缺 to_account_id

### 5. 运行日志
- 环形缓冲保留最近 500 条（时间戳 · 级别 · 模块 · 消息）
- 支持按级别过滤（错误 / 警告 / 全部）
- 支持清空

### 6. 崩溃与错误
- 上次崩溃时间与堆栈（有的话）
- 未捕获错误计数
- 最近 5 条错误详情

## 三个操作按钮

| 按钮 | 行为 |
|------|------|
| **复制诊断报告** | 生成纯文本报告到剪贴板，直接粘贴给我 |
| **导出 .txt** | 存到手机下载目录，可通过微信/QQ 发出来 |
| **开始/结束记录复现步骤** | 点开始 → 自动记录你这段时间内的页面跳转和操作 → 点结束 → 生成一条时间线，附在报告里 |

第三个按钮是关键的：**你说"点了就是失败"，配上这条时间线，我就能知道你到底点了什么、按什么顺序。**

## 隐私与脱敏

- 报告**默认不含具体金额和备注内容**，只含统计数字（记录数、体积）。
- 完整金额和备注需要你手动打开"包含明细"开关才会导出。
- 报告**不上传任何地方**——它只会进剪贴板或本地 txt 文件，你自己决定发给谁。
  （App 本身就没有联网能力，想传也传不出去。）

## 实现要点（给开发用）

- 日志框架：全局 `logger` 单例，写入内存环形数组 + 落盘到 `event_log` 表
- 全局捕获：`window.onerror` + `unhandledrejection` + Capacitor 的 `App.addListener('appStateChange')`
- 页面跳转记录：统一的路由中间件里埋点
- 完整性自检：面板打开时异步跑，结果缓存 30 秒
- 这个面板本身**不能崩**：用 try/catch 包住每一项取值，任一项失败显示"读取失败"而不是整页白屏
